# RecXchange v2

Open-form marketplace prototype. Marketing site at the repo root is untouched.

**Future host:** `v2.recxchange.io` — a separate Vercel project pointing at `apps/v2/web`, with the Go API and workers elsewhere. Do not change production `vercel.json` crons or `app.recxchange.io`.

```
# future Vercel project (commented on purpose)
# name: recxchange-v2
# rootDirectory: apps/v2/web
# env: NEXT_PUBLIC_API_URL=https://api.v2.recxchange.io
```

## Layout

| Path | Language | Port | Job |
|------|----------|------|-----|
| `apps/v2/web` | TypeScript / Next 16 | 3001 | Open marketplace + ATS + X-Ray + Admin |
| `services/api` | Go 1.23 | 8080 | Auth, entitlements, ATS, worker |
| `services/match` | Rust | 8081 | Split quote, ownership stamp, recruiter rank |
| `services/friction` | Python / FastAPI | 8082 | Advert + split Friction Lens |
| `deploy/compose.yaml` | — | — | Postgres 16 + all four processes |

Browser talks only to Go. Go calls Friction and Match.
